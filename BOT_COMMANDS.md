# FissionLab Discord — Bot Commands Reference

## MEE6 Commands (built-in)

| Command | What it does |
|---------|-------------|
| `!rank` | Shows your XP, level, and rank in the server |
| `!leaderboard` | Shows the server-wide XP leaderboard |
| `!level` | Alias for !rank |

## Slash Commands for Members

These are documented for members to use. Some require the MEE6 or Carl-bot to be fully configured.

| Command | What it does |
|---------|-------------|
| `/rank` | See your XP and current level |
| `/leaderboard` | View server rankings |
| `/resources` | Get the link to fissionlab.net/community/resources/ |
| `/book` | Get the Calendly link to book with Dr. Preston |
| `/daily` | Get today's practice question (links to #daily-question) |

## Pomodoro Study Timer

The voice channel `⏱️ Pomodoro Room` follows the 25/5 method:
- Study for 25 minutes (mics optional, camera optional)
- 5-minute break
- After 4 rounds: 15-minute long break

Preston can announce sessions in `#office-hours-info`. No bot required — members coordinate in the voice channel.

For an automated Pomodoro timer bot, add **Pomofocus Bot** or **Study Bot** from the Discord app directory.

## Dr. Preston Admin Commands

| Action | How |
|--------|-----|
| Post announcement | Use `#announcements` (locked to @Dr. Preston) |
| Award @Test Passed | Right-click member → Roles → Test Passed |
| Award @OG Member | Right-click member → Roles → OG Member |
| Award @Helper | Right-click member → Roles → Helper |
| Post office hours | Post in `#office-hours-info` with date/time and voice channel |
| Schedule daily question | MEE6 dashboard → Scheduled Posts (see MEE6_SETUP.md) |
