# Calculus II — Problem Set
**USNA Validation Prep** | Easy → Hard (multiple-choice format mirrors exam)

---

## Section 1: Integration Techniques (Easy–Medium)

**1.** Evaluate ∫ x√(x²+1) dx.

**2.** Evaluate ∫ x·cos(x) dx using integration by parts.

**3.** Evaluate ∫ sin³(x) dx.

**4.** Evaluate ∫ x²/(x²−4) dx. (Hint: polynomial long division first, then partial fractions)

**5.** Evaluate ∫ 1/(x²+2x+5) dx. (Complete the square first)

**6.** Evaluate ∫ √(9−x²) dx using trig substitution. (Hint: x = 3 sin θ)

---

## Section 2: Applications (Medium)

**7.** Find the area of the region enclosed by y = x² and y = x + 2.

**8.** Find the volume when y = x², from x = 0 to x = 2, is rotated about the x-axis (disk method).

**9.** Find the volume when y = √x, from x = 0 to x = 4, is rotated about the y-axis (shell method).

**10.** Find the arc length of y = (2/3)x^(3/2) from x = 0 to x = 3.

**11.** Determine if ∫₁^∞ 1/x² dx converges or diverges. If it converges, find its value.

**12.** Determine if ∫₀¹ 1/√x dx converges. If so, evaluate.

---

## Section 3: Sequences & Series (Medium–Hard)

**13.** Does the series Σ_{n=1}^∞ n/(n²+1) converge or diverge? Use the integral test.

**14.** Does Σ_{n=1}^∞ 1/n² converge? Use the p-series test. What about Σ 1/√n?

**15.** Test for convergence: Σ_{n=0}^∞ (3/4)ⁿ. If it converges, find the sum.

**16.** Use the ratio test: Σ_{n=0}^∞ n!/3ⁿ.

**17.** Use the ratio test: Σ_{n=0}^∞ xⁿ/n!. Find the interval of convergence.

**18.** Determine if Σ_{n=1}^∞ (−1)ⁿ/n converges absolutely, conditionally, or diverges.

---

## Section 4: Power Series & Taylor/Maclaurin (Hard)

**19.** Find the Maclaurin series for f(x) = eˣ up to the x⁴ term. Use it to approximate e^(0.1).

**20.** Write the first four nonzero terms of the Maclaurin series for sin(x²).

**21.** Use the known series for 1/(1−x) to find the power series for 1/(1+x²), then integrate to get the series for arctan(x).

**22.** Find the Taylor series for f(x) = cos(x) centered at a = π/2 up to the (x−π/2)³ term.

**23.** Use the first two nonzero terms of the appropriate Maclaurin series to approximate ∫₀^(0.5) sin(x)/x dx. (Hint: sin(x)/x = 1 − x²/6 + x⁴/120 − ···)

---

## Section 5: Parametric & Polar (Hard)

**24.** For the curve x = t² − 1, y = t³ − t: find dy/dx. At what values of t is the tangent horizontal? Vertical?

**25.** Find the area enclosed by the cardioid r = 1 + cos(θ).

**26.** Find the arc length of the curve x = cos(t), y = sin(t), from t = 0 to t = 2π. What curve is this?

---

## Challenge (Free-Response Style)

**27.** A sequence is defined by a₁ = 1 and aₙ₊₁ = √(2aₙ + 1).
(a) Compute a₂, a₃, a₄.
(b) Assuming the sequence converges, find its limit L.
(c) Explain briefly why convergence is plausible (monotone bounded argument).

**28.** Let f(x) = x sin(x).
(a) Find the Maclaurin series for f(x) up to the x⁵ term.
(b) Use it to compute lim(x→0) (x sin x − x²)/x⁴.
(c) Evaluate ∫₀¹ x sin(x) dx two ways: (1) integration by parts; (2) term-by-term integration of the series. Confirm they agree.
